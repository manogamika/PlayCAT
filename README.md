# PlayCAT

A simple app for CAT (Computer Assisted Test) available for Android and Linux (Arch), replacing Google Forms with a teacher-based question bank. Built using [MoonBit](https://www.moonbitlang.com/) and [Kotlin](https://kotlinlang.org/), it features an integrated tokenizer, screen pinning, non-split screen mode, and robust security against deep debug access and mock locations. This is an experimental project intended for educational purposes.
